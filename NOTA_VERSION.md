# Nota técnica de versión: v0.1.0

## Contenido de la versión
Base documental y de diseño del Sistema de Gestión de Citas Médicas: requisitos funcionales y no funcionales con criterios de aceptación, cuatro diagramas UML, arquitectura en capas con separación frontend/backend, tablero con 10 tareas técnicas y matriz de 4 riesgos. No incluye código de aplicación.

## Cambios controlados
- Requisitos especificados y vinculados a Issues
- Modelos UML elaborados y validados entre sí
- Arquitectura definida y justificada
- README actualizado con la organización frontend/backend
- Tablero actualizado con el estado real del avance

## Pendientes
- Diseño del esquema de la base de datos
- Autenticación y control de acceso por rol
- Validación de disponibilidad de horarios
- Notificaciones automáticas de recordatorio
- Pruebas funcionales, de seguridad y de carga

## Próximo paso técnico
Diseñar el esquema de la base de datos a partir del diagrama de clases (Paciente, Doctor, Cita, Notificación) y levantar el esqueleto del backend con autenticación por rol, para luego implementar el registro de pacientes y el agendamiento de citas.
