# Matriz de Riesgos – Sistema de Gestión de Citas Médicas

| Riesgo | Acción de respuesta |
|--------|---------------------|
| **Retraso en la entrega del diseño de la base de datos.** | Priorizar esta tarea y asignar seguimiento diario hasta que pase a finalizado antes de iniciar tareas de desarrollo. |
| **Sobrecarga de tareas a un solo responsable.** | Redistribuir las tareas entre los roles definidos en el tablero y ajustar las fechas estimadas si un responsable acumula más de 3 tareas activas. |
| **Requisitos mal definidos.** | Revisar y validar los requisitos con una segunda pasada antes de empezar el modelado, así evitamos avanzar con requisitos ambiguos. |
| **Fallos de seguridad en el módulo de autenticación por falta de pruebas adecuadas.** | Incluir pruebas específicas de autenticación y de control de acceso antes de mover la tarea a finalizado. |
